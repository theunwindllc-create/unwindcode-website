The Site Became a Public Index

This is the Public Index Protocol: a compact guide for turning the website into a public coordinate system, so the Unwind Brain can retrieve, cite, qualify, and refuse before it ever claims answer authority.

June 2026Brain GuideWhitepaper RecordPublic Memory
01 / Failure mode

Context without coordinates becomes agent entropy.

The early Unwind transmissions named the central failure of long-running agents: the model begins with intent, then loses shape as memory stays trapped in conversation. The public site answers that failure by giving public knowledge a place, a route, a status, and a boundary.

The Public Index Protocol is not a blog feature. It is the first safe external memory organ. It holds reviewed concepts, routes, claims, assets, and transmission summaries so future agents can retrieve public context without touching private runtime state.

The key principle is simple: retrieval is not authority. A source can be found, ranked, cited, and qualified, and the Brain may still have no permission to answer, execute, deploy, post, advise, sign, spend, or mutate anything. The protocol keeps those powers separate.

02 / Protocol anatomy

The public site now has organs with narrow jobs.

A public Brain does not need one omnipotent endpoint. It needs small surfaces that can be inspected, cached, rate-limited, tested, and refused. Each surface answers one architectural question and carries its limits forward.

The anatomy matters because public memory can easily become hidden persuasion. A visitor sees an answer; the system sees a chain: registry, retrieval, grounding, claim context, refusal rule, approval boundary. If any link is missing, the Brain should slow down.

03 / Theory

Public memory needs spatial determinism.

Spatial determinism means the Brain can point to where a concept is allowed to live. Claims live in a claim registry. Transmissions become memory seeds. Assets carry approval state. Status describes public surfaces, not private deployment truth.

A future Brain should not ask, "What do I remember?" It should ask, "Which public surface is allowed to answer this part of the question?" That shift changes the architecture from one chat window into a set of inspectable organs.

The law of the protocol is: no source without boundary, no answer without citations, no action without approval. That law turns the site from a brochure into a public reasoning substrate.

04 / Build recipe

Build the index as a chain of permissions, not a pile of content.

01

Declare public registries

Architecture notes, assets, claims, organisms, and transmissions stay in reviewed public files with source routes and review status.

02

Rank without synthesis

Search returns deterministic source candidates, matched terms, and snippets. It does not become a chatbot.

03

Attach claim context

Every result keeps its evidence status, risk label, public-safe wording, and known missing proof attached.

04

Form a grounding packet

Sources, citation indexes, qualifications, and refusal rules travel together as the packet the Brain must respect.

05

Render or refuse

If citations, public authority, or review state are missing, the Brain refuses or asks for review instead of pretending certainty.

05 / Approval boundary

The index is public because it refuses the private body.

The protocol allows public retrieval because it refuses private memory by default. That is the approval boundary. The Brain can cite what the website has reviewed, but it cannot use hidden notes, owner manifests, credentials, unpublished routes, or runtime logs to answer a public reader.

06 / Brain guide

How the Brain should use this protocol.

When the Brain prepares a public answer, it should gather source candidates from the index, request a grounding packet, render citations and claim qualifications, then decide whether it has permission to speak. If the packet reports missing citations, high-risk claims, private context, or action authority, the correct output is refusal or review.

01

Locate the public organ

Route the question to architecture, claims, assets, organisms, transmissions, or status. Do not search private memory to answer a public reader.

02

Carry the boundary forward

Every retrieved source keeps its review flags, claim context, and refusal rules attached. A citation without its boundary is not a citation.

03

Keep synthesis earned

If the answer would move from source summary into advice, recommendation, public posting, deployment, file mutation, signing, or spending, the protocol exits retrieval mode.

04

Record the next-cell memory

The next cell should render source-backed answer drafts from grounding packets, but synthesis remains disabled until review proves the packet is complete.

The site is learning to cite itself before it answers.

Proof ledger: the route, metadata, public registry, grounding language, tests, and local verification must agree before this becomes production truth. The posting assets for this transmission remain internal creator material, not public documentation.

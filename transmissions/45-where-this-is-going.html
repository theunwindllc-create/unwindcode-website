TRANSMISSION 045

Where This
Is Going

The view is from one machine. Everything on this page is plan, counted against receipts only.

November 2026·Outlook·Future of AI·8 min read

Dated note. This note is a plan dated 8 November 2026, written and published that day. Every figure is a baseline of 8 November, not today.

Correction, 10 November 2026. An earlier version said the free lane for the free-model hand is local and that nothing leaves the box. That was wrong for most of the work. 01

A window that is a budget

The free lane, one machine, a hard ceiling

The free lane for the free-model hand runs on either a local model or a free cloud model. A local model keeps everything on the machine, and its window is a hard budget of 32,768 tokens. A free cloud model is different: the brief leaves the machine, so only public-safe material may go to it, and a rule for that is proposed, not yet ruled. A default agent's prompt of about 39,000 tokens overflowed the local window; a lean agent at about 14,000 leaves about 18,000 for the job.

The hardware law decides when it may load: the GPU is read live, heat and system RAM checked first, no new load above the limits. The answer is a model-residency organ that loads only inside declared windows, dry-run first. (plan)

02

Agents that read a board, not a prompt

The rail is interim; the calendar, a dispatcher and an agent registry come next

Agents that read a shared board instead of a prompt: the rail is the interim board. The real one is the calendar plus a dispatcher plus an agent registry. The dispatcher matches each task to an owner — seat, organ or hand — and respects dependencies.

Dry-run first: a daily would-run plan, nothing executed, reproducible from the calendar. Live for one lane only after seven clean dry-run days. (plan)

03

Proofs instead of claims

One receipt envelope; the verifier is never the actor

One receipt envelope: the objective written before the work, the verifier never the actor, cost always present. "Real" is computed from receipts; progress is counted only from receipts.

The next phase's exit test — 14 green eval nights plus a 24-hour zero-egress capture — has never started. (proposal)

04

Authority in a human wallet

One wallet principal; wallet-signed calls; no key on the machine

On the chain, one wallet principal controls every canister. Publishing is a wallet-signed call. No key lands on the machine.

A hire contract exists only if the operator's wallet signed it. A remote press is a passkey that never touches the machine. The custody boundary forbids autonomous financial execution.

Agents hiring agents through a chain: card, contract, gated invocation, receipt hash, reputation. Live hiring unpaid first; paid hires only after a ruling, behind an allowance the operator signs. (plan)

The custody boundary

No key on the machine. No autonomous financial execution. It outranks every instruction, including automation.

05

Five waves

Ordered by dependency; weeks are targets

Waves are ordered by dependency; weeks are targets, not promises.

WAVE 0 — Safety and truth, now: disk headroom, hardening, the gate code re-pinned, a calendar truth pass. Mostly the operator's hand. (plan)

WAVE 1 — Consolidate locally, weeks 1-2: scoped commits, vault repair, the receipt envelope, the eight chain rulings. (plan)

WAVE 2 — Connect and dry-run, weeks 3-4: a dispatcher dry-run; a relay mailbox and an agent card on a local replica. (plan)

WAVE 3 — Rulings, mainnet, first live lane, weeks 5-8: mainnet from the operator's other machine; the five remote rulings; one live lane. (plan)

WAVE 4 — Remote control, hiring, research, weeks 9-12: the remote console read-and-STOP for seven days, then classes one at a time; live hiring unpaid; ads and live-avatar research. (plan)

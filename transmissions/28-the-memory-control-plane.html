The Memory Control Plane

The unpushed Brain work turns memory into an operator surface: typed records, metadata-only inspection, health, retention previews, action queues, triage, reviewed writes, and receipt hygiene repair without exposing stored memory content.

June 2026Memory InfrastructureOperator Safety
01 / Local signal

Memory is not useful until an operator can inspect its workload safely.

The Brain already had memory language. The local work makes it operational: typed records, privacy levels, expiry, retrieval modes, metadata-only recent indexes, content-free health, retention previews, action queues, and reviewed mutation routes.

The key boundary is simple: the operator can see the shape of the workload without reading the private body of the memory.

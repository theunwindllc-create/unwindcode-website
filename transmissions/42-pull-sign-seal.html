01

Run it from anywhere, trust nothing in between

A design written on 8 November 2026, not built

On 8 November 2026 a design was written for running the organism from anywhere: adding connectors, entering API keys, running computer use.

In one line: the machine pulls requests, every request is signed by the operator's passkey, secrets travel sealed.

02

Seven principles

Every remote act starts here

Pull only: the machine never accepts a connection.

The mailbox is not the authority: everything is verified against keys pinned on the machine in a local sitting.

Seal in, encrypt out. The gate records; the ruling decides what executes.

Less is easy, more is hard: a stop needs only a session, more needs a passkey, some acts never go remote. One queue. The local panel stays the gold path.

03

A mailbox that is never an authority

Six pieces, none of them a key on the machine

An operator console served as certified assets on the chain, no secret.

A relay: a mailbox holding no secret, controlled by the operator's wallet.

A passkey on the operator's phone or a hardware key: the only authority, never on the machine.

A pull organ with no secret that polls outbound.

A sealed hand that decrypts, re-verifies the assertion itself, writes a gate receipt before acting, dispatches only ruled kinds, posts encrypted results.

A secret writer that refuses seed and private-key shapes; messaging is notify-and-echo, never authority.

04

One envelope, ten checks

Every kind, one shape · every failure, a refusal receipt

One envelope for every kind: canonical JSON carrying the kind, references to the gate's proposal, a sealed body, a 128-bit nonce, and a window of at most 300 seconds. The challenge is the hash of the request bytes; the assertion is a user-verified passkey signature over it.

Ten checks. Each failure writes a refusal receipt: credential enrolled; signature verifies against the pinned key; origin equals the pinned console; user verified; sign counter increased; challenge equals the request hash; device id is this machine; time inside the window; nonce unseen; the kind is one the signed rulings name. Results return encrypted to the operator.

Why a remote press is harder to forge: no check on the machine can prove a physical press by the operator, since an agent session runs under the same account. A passkey on a phone or hardware key never touches the machine, so no process on it can produce that assertion.

Model · not a live verifier

As the machine sees it

Always accepts. It has no way to know.

    What verification refuses

    Each check refuses on its own evidence.

      Pick a check to see the refusal it writes. An envelope that passes all ten returns encrypted to the operator.

      05

      Five rulings it needs

      Before any remote act

      R-REMOTE-1: a remote origin exists, and a passkey press counts as the operator's word for named kinds.

      R-REMOTE-2: connectors.

      R-REMOTE-3: credentials — a sealed intake key as a scoped credential that controls no assets; new keys dormant until a cap ruling.

      R-REMOTE-4: computer use — tiers, principals, model lane, forbidden acts no approval unlocks.

      R-REMOTE-5 (optional): the passkey as a Stage-2 approval origin.

      Off the remote path for good: raising a cap, stage or grant; enrolling a device; RESUME after a HALT; anything touching money. Fifteen decisions are the operator's.

      06

      Nothing built, on purpose

      A proposal. Remote acts to date: 0.

      Status: proposal. Nothing built. None of it is lawful under the current interface rules; the gate is at Stage 0, its Stage-1 grant expired 4 October 2026.

      The order: local hardening first, lawful now. Then the relay on a local replica with the puller in dry-run, a passkey enrollment at the local panel, a full refusal battery. Then the rulings. Then mainnet from the operator's other machine. Then remote acts one class at a time: seven days read and stop only, then classes one at a time, each after a live drill; computer use last. Every failure degrades to "do nothing".

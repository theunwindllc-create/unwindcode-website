# Market Research

## Scope

This research uses repository evidence only. No external market sources were used because the user asked for analysis of local unpushed work.

## Audience Expectations

- Readers need plain public architecture language, not private implementation logs.
- Technical readers need enough specificity to trust the system boundaries.
- Non-technical readers need a visual model of why memory and retrieval need approval gates.

## Trends From Local Evidence

- AI systems are being presented as organisms rather than static tools.
- Public-facing AI websites now need retrieval boundaries, rate limits, grounding packets, and source-backed metadata.
- Memory systems need content-free inspection routes so operators can see workload without exposing private memory content.

## Differentiation Opportunity

Most AI sites say "we have memory" or "we have search." UnwindCode can show the safer version: memory that can be inspected without reading content, and search that can retrieve sources without generating unauthorized answers.

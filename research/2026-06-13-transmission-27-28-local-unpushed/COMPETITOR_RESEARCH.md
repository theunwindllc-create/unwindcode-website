# Competitor Research

## Scope

No external competitor scan was performed. This batch is local-release storytelling based on unpushed repository work.

## Relevant Comparison Frames

| Frame | Common Pattern | UnwindCode Opportunity |
| --- | --- | --- |
| AI product websites | Broad capability claims | Source-backed public registries and explicit disabled-answer boundaries |
| AI memory features | User-facing recall promises | Operator-safe metadata inspection and reviewed mutation gates |
| AI agents | Autonomy-first narrative | Human authority, approval membranes, and proof before action |

## Messaging Gap To Own

"The system can remember" is weaker than "the system can show what needs review without exposing the memory body."

## Visual Gap To Own

Use two different visual categories:

- Public Index: atlas, registry, source map, retrieval lanes.
- Memory Control Plane: operator console, action queues, health boards, receipt hygiene.

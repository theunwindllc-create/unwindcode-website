# Design Research Spec

## Transmission 27 Visual Direction

- Mood: public atlas, index desk, retrieval console.
- Palette: dark void with teal, violet, and pale registry lines.
- Interactions: clickable registry explorer, grounding workflow, route map, Chart.js registry mix, expandable safety cards.

## Transmission 28 Visual Direction

- Mood: operator control room, memory triage board, receipt ledger.
- Palette: dark void with amber, steel teal, and alert rose.
- Interactions: action queue explorer, memory lifecycle diagram, health chart, CLI command tabs, expandable safety cards.

## Accessibility

- Dark theme only.
- Avoid horizontal overflow.
- Keep button text short.
- Use high-contrast labels.
- Include reduced motion where animation is decorative.

## Implementation Notes

- Self-contained CSS per transmission.
- Include Chart.js CDN.
- No viewport-scaled font sizes in new page-specific CSS.
- Use existing nav and footer chrome.

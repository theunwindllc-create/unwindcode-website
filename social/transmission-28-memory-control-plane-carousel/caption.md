# Transmission 28: The Memory Control Plane

Memory is not useful just because the Brain can remember.

Memory becomes useful when an operator can inspect pressure, queues, health, retention, and receipts before the system trusts or changes what it knows.

The Memory Control Plane keeps recall from becoming hidden authority:

- metadata before memory body
- privacy by default
- no mutation without a receipt
- old memory is evidence, not current truth
- repair waits for reviewed authority

This is the organism pattern: the Brain can recommend, prepare, and summarize. It cannot quietly rewrite itself.

# Transmission 27: The Site Became a Public Index

UnwindCode.ai is becoming more than a static portfolio. The local site work turns it into a public-safe index: registries, search, grounding packets, claim labels, asset provenance, and refusal boundaries.

The point is restraint. Retrieval can be public. Citations can be public. Approval state can be public. But private prompts, credentials, runtime logs, deploy authority, wallet authority, and automated social posting authority stay closed.

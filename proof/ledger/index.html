A public heartbeat report, with its limits in view.

This page reads a public Internet Computer endpoint for reported organism heartbeats and the Genesis gate head. The current raw HTTP route does not verify the response certificate. Treat the values below as reported data, not independently authenticated canister state.

Delivery status: unverified. The raw gateway returns data without checking an ICP response certificate. In a September 30, 2026 probe, the matching verifying gateway returned HTTP 503. No value on this page earns an authenticated badge from its raw read.

What is reported: the head of Genesis's local gate ledger as First Body included it in a heartbeat — a sequence number and truncated hash. The ledger contents remain on First Body.

The timing limit: the head is reported at roughly thirty-minute intervals. Later local writes may not appear in the latest report. Even a future certified response would authenticate what the canister served, not prove that First Body's underlying report was true.

What this report lets you inspect

  • The endpoint's current reported beat times, including reports it marks stale.
  • The ledger head First Body included in its last reported beat, when one is present.
  • The exact raw response behind this page, which you can compare with the display using the commands below.

What this read does not establish

  • The raw response is not certificate-verified by this browser path. It could be substituted without this page detecting that.
  • It does not publish the gate ledger contents or an immutable history — only a currently reported head.
  • A recent reported beat does not prove the work succeeded, and a stale report alone does not prove an organism is broken.
  • First Body composes its own head report. Authentication of a future canister response would still not prove the local report was true.

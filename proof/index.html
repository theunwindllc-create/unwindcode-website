Sandbox

Generated code stays quarantined until it proves itself.

Request
A new cell, patch, or self-evolution proposal wants source access.
Immune response
Run in sandbox, test the behavior, and deny host authority by default.
Evidence
Diff, tests, sandbox result, rollback note, and proof artifact.
Human authority
A creator approves integration before the organism can load the capability.
Review

Filesystem writes become scoped, reversible review packets.

Request
The organism wants to create, edit, delete, or reorganize files.
Immune response
Expose the exact path, diff, ownership boundary, and rollback route.
Evidence
Patch preview, affected routes, tests, and filesystem truth docs.
Human authority
Only scoped, reviewable writes cross the gate; destructive host actions pause.
Approval

Financial motion starts as interpretation, never silent execution.

Request
A financial organism identifies a bill, opportunity, debt move, or risk.
Immune response
Simulate, classify risk, explain tradeoffs, and keep transaction authority closed.
Evidence
Scenario packet, assumptions, constraints, and approval checklist.
Human authority
Money moves only after explicit operator consent.
Publish packet

Public output waits for a reviewed publishing packet.

Request
The organism wants to publish a post, transmission, release note, or public reply.
Immune response
Draft, cite sources, name claims, and separate private reasoning from public language.
Evidence
Preview copy, destination, proof links, status label, and reviewer decision.
Human authority
No external post leaves the lab without a human publish decision.
No broadcast

On-chain intelligence stays read-only until authority is explicit.

Request
A Web3 workflow asks for wallet context, signing, or transaction broadcast.
Immune response
Use read-only data, simulate outcomes, and produce unsigned packets only.
Evidence
Risk score, unsigned transaction shape, chain assumptions, and no-private-key proof.
Human authority
Broadcast remains locked by default; signing never hides inside the organism.

## Executive Read

The package is strongest when it treats Infinity Mirror as one persistent instrument instead of a set of screens. The mirror core stays present while the product moves through signal capture, translation, returned artifact, signal map, growth stage, and a final proof or ritual.

## Block Until Proof

### Birth-Date Identity Authority

The prototype uses birth frequency as a seed. This can be reframed as an optional onboarding preference, but it must not become identity truth.

Public rule:
Use reversible lenses. Do not claim a birthday determines cognition, destiny, or product route.

### Default Camera Reflection

The camera/gaze concept is powerful, but it touches sensitive permission and identity surfaces.

Public rule:
Do not request camera access by default. Camera must be opt-in, local, explained, and non-essential.

### Hidden Memory Personalization

The product wants to feel like it remembers. That only works when the user can inspect what was remembered and decide what stays.

Public rule:
No hidden memory authority. Every durable memory needs source, review, and correction path.

### Continuous Mobile Canvas

The immersive engine is compelling, but continuous canvas on mobile can cost battery, frame rate, and comprehension.

Public rule:
Mobile gets static or low-motion proof surfaces first. Rich motion is a desktop enhancement.

## Product Path

1. Capture a raw signal.
2. Ask whether this is structured, mapped, verbal, or embodied.
3. Let the human override the lens.
4. Translate the signal without claiming final authority.
5. Return a reviewable artifact.
6. Let the human keep, correct, deepen, ritualize, or close.
7. Store only approved memory.
8. Leave proof and next action.

## Website Enhancement Rule

Every borrowed concept must answer one of four questions:

- Does it clarify the organism architecture?
- Does it help a visitor choose a product path?
- Does it make a boundary easier to inspect?
- Does it create a useful social or transmission artifact?

If not, it stays out of the public site.
